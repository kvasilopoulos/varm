# varm: Fast Vector Autoregressions and Local Projections with an Rcpp Engine

Frequentist and Bayesian vector autoregressions (VAR), structural
identification, and local projections (LP) with a C++
(Rcpp/RcppArmadillo) engine. MCMC samplers (Minnesota conjugate and
hierarchical priors, stochastic-volatility triangular Gibbs, shrinkage
priors, TVP-VAR) run entirely in compiled code.
